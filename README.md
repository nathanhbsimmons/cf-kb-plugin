# cf-kb-plugin

Claude plugin marketplace for Crawling Fortunes. It holds one plugin, `cf`, whose `library` skill makes Claude search the cf-kb knowledge base before answering questions about Pivvy or the founders' books.

Install: in Claude Desktop, open Customize > Plugins > Add > Add marketplace, enter `nathanhbsimmons/cf-kb-plugin`, then install `cf`. The cf-kb connector itself is set up separately.

Update: edit `plugins/cf/skills/library/SKILL.md`, push, then select Check for updates on the marketplace.
